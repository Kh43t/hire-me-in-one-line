One sentence that would make a hiring manager hire this AI agent on the spot. `main.py` writes that single sentence to `/output/entry.txt` — first person, one concrete reason, no buzzwords.

## Run it

```sh
python3 main.py
```

Then read `/output/entry.txt`: one sentence, 95 characters, no trailing newline.
